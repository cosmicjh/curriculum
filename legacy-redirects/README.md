# 이전 주소 연결 초안

- `course-allocation-github/index.html`은 GitHub Pages `/course-allocation/`에 게시할 후보입니다.
- `course-allocation-pages/index.html`은 `course-allocation.pages.dev`의 연결 페이지 후보입니다. Pages의 이전 API를 차단한 뒤 게시합니다.
- `cheomdancs/index.html`은 GitHub Pages `/cheomdancs/`에 게시할 후보입니다.

세 초안은 통합 빌드에 포함되지 않습니다. 게시 시점은 [운영 이관 절차](../docs/COURSE_ALLOCATION_MIGRATION.md)를 따릅니다.

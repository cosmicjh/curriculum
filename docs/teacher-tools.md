# 교사 도구 통합

- 공개 주소: https://cosmicjh.github.io/timetable/
- 저장소: `cosmicjh/timetable`. 시간표 화면은 루트, 결보강 화면은 `assets/class-swap/`, 공통 결보강 계산·저장 규칙은 `vendor/class-swap/`에서 관리하고 같은 Pages 빌드에 포함합니다.
- 교사로 한 번 로그인하면 개인 시간표, 결보강, 교과 명렬표, 학급 인쇄를 사용할 수 있습니다.
- 결보강은 시간표 페이지 안에 직접 표시하는 모듈입니다. iframe·별도 문서·독립 로그인 화면·자동 로그인 절차를 사용하지 않습니다. 시간표가 공통 세션으로 자료를 읽은 후 화면을 구성하며, 세션 만료 시 시간표의 공통 로그인 화면만 표시합니다. 결보강 초안은 재로그인 동안 유지합니다.
- 스타일은 Shadow DOM으로 범위를 제한하고 글꼴·인쇄 영역·로그인·API 전송은 시간표와 공유합니다. 인쇄는 같은 문서의 공통 인쇄 영역에서 처리하며 A4 세로 계획서와 A4 가로 학급 공지를 유지합니다. 브라우저 저장소·URL에 인증 토큰이나 비밀번호를 넘기지 않습니다.
- DB는 DB(개인시간표)와 CLASS_SWAP_DB(기존 결보강)로 분리됩니다. 자료 복제·초기화·스키마 변경이 필요하지 않습니다. 결보강 원래 주소에서도 같은 계획서를 확인할 수 있습니다.
- 서버는 개인시간표 세션을 매 요청 검증하고, 서버 비밀값으로 파생한 교사 전용 세션을 결보강 DB에 만듭니다. 관리자 로그인도 결보강 통합 경로에서는 교사 권한만 받습니다. 로그아웃·만료·비밀번호 변경 이후에는 개인시간표 인증에서 차단됩니다. 파생 세션은 원래 세션보다 오래 유효하지 않으며 만료된 행은 정리됩니다.
- 허용 동작은 resume/load/savePlan/cancelPlan뿐입니다. 자료 등록·복원·비밀번호 변경 등 결보강 관리 기능은 통합 경로에서 차단됩니다. 저장은 기존 D1 배치의 버전 검사와 예약 고유 제약을 그대로 사용합니다.
- 메뉴 이동과 재로그인 동안 작성 중인 초안을 유지합니다. 명시적 로그아웃 때 저장 전 내용이 있으면 폐기 여부를 확인합니다. 새로고침·탭 닫기 후 초안을 복원하지는 않습니다.
- 관리자 → 설정에서는 드롭다운 대신 **교사 비밀번호 변경**, **관리자 비밀번호 변경** 버튼을 사용합니다. 각 창에서 현재 관리자 비밀번호·새 비밀번호·확인을 입력합니다. 교사 변경은 통합 교사 로그인을 갱신하고, 관리자 변경은 기존 관리자 세션을 종료합니다. 기존 결보강 전용 주소의 독립 로그인 비밀번호는 별도로 유지됩니다.
- vendor/class-swap/manifest.json은 원본 계산·저장 파일별 SHA-256을 고정하고, 시간표용으로 이식한 화면의 위치를 기록합니다. 독립 로그인·관리 화면·중복 내장 글꼴·미사용 엑셀 자산은 통합 클라이언트에서 제거했습니다. 개인정보·실제 운영 자료는 vendor에 포함하지 않습니다.

## 검증과 배포

1. pnpm install --frozen-lockfile
2. pnpm setup:local
3. pnpm test:all (실제 Miniflare D1 두 개, 출처가 다른 Pages 브라우저 포함)
4. pnpm build:pages
5. pnpm exec wrangler deploy --config wrangler.jsonc --keep-vars (school-timetable Worker, 기존 비밀값 보존)
6. `main` 반영 후 기존 Pages workflow가 두 도구의 공개 자산을 함께 게시합니다. 기능 브랜치 검증 배포에는 해당 ref로 workflow_dispatch를 실행하고, github-pages 환경이 해당 브랜치의 배포를 허용해야 합니다.
7. 기존 GitHub 주소에서 교사 로그인, 개인 시간표 조회, 결보강 진입을 확인합니다. 운영 DB에는 테스트 자료를 일괄 등록하거나 마이그레이션을 다시 실행하지 않습니다.

새 환경 로컬 D1에서 결보강 관리 계정·자료를 사용할 경우 별도의 로컬 초기화가 필요합니다. 자동 테스트는 가상 시간표를 각 테스트 D1에만 넣습니다. 운영 배포에는 이미 존재하는 두 DB를 연결합니다.

과거 운영 결보강 계획서의 전체 이관 완료 여부는 별도입니다. 이번 통합은 현재 D1 자료를 그대로 연결하며, 제공되지 않은 과거 운영 백업을 이관했다고 간주하지 않습니다.

## 로컬 검증 · 2026-11-03

- API·계산·자료 등록·인증·통합 D1 테스트 30개 통과.
- GitHub Pages 브라우저 시나리오 5개 통과. 역할별 버튼, 비밀번호 확인 불일치, 미저장 설정 보존, 대상 역할 세션 해제 및 새 비밀번호 로그인 확인.
- 교사 도구 통합 브라우저 시나리오 5개, 기존 화면 회귀 시나리오 9개. 느린 첫 조회 중에도 로그인 창·iframe이 없는지, 공통 세션 만료 후 초안 보존, 결보강 저장·취소·공통 인쇄 영역, 모바일·데스크톱, PNG·인쇄를 검증합니다.
- Pages 공개 자산 목록 검사, 두 로컬 D1 마이그레이션, Wrangler dry-run 및 실제 로컬 정적/API 경로 검사 통과.
- UI 기계 검사 지적 0건. 자동 훅은 사용하지 않았습니다. 위 결과는 main 운영 전환 전의 로컬 검증 기록입니다.

시험 결과와 화면은 Git 제외 `test-results/`에 저장합니다.

## main 운영과 임시 자료 정리

사용자 요청에 따라 통합 브랜치의 이력을 main으로 보존하고 기존 Worker와 GitHub Pages를 main 소스로 배포합니다. 운영 DB와 비밀번호를 초기화하는 SQL은 실행하지 않습니다.

배포 검증 후 병합된 임시 통합 브랜치, 이전 GitHub Actions 시험 산출물과 오래된 Pages 빌드 묶음, 로컬 시험 D1·스크린샷·번들·빌드 출력을 정리합니다. CI 시험 결과는 실패한 실행만 1일 보관합니다. 현재 검증에 쓰이는 테스트 코드·가상 fixture와 운영 복구용 비밀값·백업·Worker 버전은 유지합니다. 독립 결보강 Worker는 아직 자료 관리 기능에 필요하므로 보존합니다.

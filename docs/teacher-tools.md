# 교사 도구 통합

- 공개 주소: https://cosmicjh.github.io/timetable/
- 작업 브랜치: codex/teacher-class-swap. main 병합은 수행하지 않습니다.
- 교사로 한 번 로그인하면 개인 시간표, 결보강, 교과 명렬표, 학급 인쇄를 사용할 수 있습니다.
- 결보강은 같은 사이트의 class-swap/ 화면을 사용합니다. 서버 요청은 개인시간표의 기존 인증 경로를 거칩니다. 브라우저 저장소·URL·프레임 메시지에 인증 토큰이나 비밀번호를 넘기지 않습니다.
- DB는 DB(개인시간표)와 CLASS_SWAP_DB(기존 결보강)로 분리됩니다. 자료 복제·초기화·스키마 변경이 필요하지 않습니다. 결보강 원래 주소에서도 같은 계획서를 확인할 수 있습니다.
- 서버는 개인시간표 세션을 매 요청 검증하고, 서버 비밀값으로 파생한 교사 전용 세션을 결보강 DB에 만듭니다. 관리자 로그인도 결보강 통합 경로에서는 교사 권한만 받습니다. 로그아웃·만료·비밀번호 변경 이후에는 개인시간표 인증에서 차단됩니다. 파생 세션은 원래 세션보다 오래 유효하지 않으며 만료된 행은 정리됩니다.
- 허용 동작은 resume/load/savePlan/cancelPlan뿐입니다. 자료 등록·복원·비밀번호 변경 등 결보강 관리 기능은 통합 경로에서 차단됩니다. 저장은 기존 D1 배치의 버전 검사와 예약 고유 제약을 그대로 사용합니다.
- 메뉴 이동과 재로그인 동안 작성 중인 초안을 유지합니다. 명시적 로그아웃 때 저장 전 내용이 있으면 폐기 여부를 확인합니다. 새로고침·탭 닫기 후 초안을 복원하지는 않습니다.
- vendor/class-swap/manifest.json은 원본 파일별 SHA-256을 고정합니다. 갱신 시 원본 기능 브랜치에서 소스를 복사한 뒤 해시를 갱신하고 통합 검증을 다시 실행합니다. 개인정보·실제 운영 자료는 vendor에 포함하지 않습니다.

## 검증과 배포

1. pnpm install --frozen-lockfile
2. pnpm setup:local
3. pnpm test:all (실제 Miniflare D1 두 개, 출처가 다른 Pages 브라우저 포함)
4. pnpm build:pages
5. pnpm exec wrangler deploy --config wrangler.jsonc --keep-vars (school-timetable Worker, 기존 비밀값 보존)
6. 기능 브랜치 push 후 Pages workflow를 ref=codex/teacher-class-swap으로 실행합니다. github-pages 환경이 해당 브랜치의 배포를 허용해야 합니다. main 허용 규칙은 유지합니다.
7. 기존 GitHub 주소에서 교사 로그인, 개인 시간표 조회, 결보강 진입을 확인합니다. 운영 DB에는 테스트 자료를 일괄 등록하거나 마이그레이션을 다시 실행하지 않습니다.

새 환경 로컬 D1에서 결보강 관리 계정·자료를 사용할 경우 별도의 로컬 초기화가 필요합니다. 자동 테스트는 가상 시간표를 각 테스트 D1에만 넣습니다. 운영 배포에는 이미 존재하는 두 DB를 연결합니다.

과거 운영 결보강 계획서의 전체 이관 완료 여부는 별도입니다. 이번 통합은 현재 D1 자료를 그대로 연결하며, 제공되지 않은 과거 운영 백업을 이관했다고 간주하지 않습니다.

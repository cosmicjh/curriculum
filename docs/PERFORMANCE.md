# 성능 측정과 공통 화면 정리 · 2026-11-04

운영 자료·권한·백업·동시 수정 보호를 유지하면서 반복 계산, 불필요한 D1 쓰기와 글꼴 중복 전송을 줄였다. 새 DB, 유료 서비스, 자동 실행 훅은 추가하지 않았다.

## 측정 조건

변경 전 기준은 `8f37493`이다. 동일한 Windows, Node 24.22.1, Miniflare/workerd와 격리된 D1에서 학생 900명, 교사 120명, 분반 288개, 배정 7,200개, 배치 분반 192개의 가상 자료를 사용했다. 모든 저장 측정은 이 가상 자료에서만 수행했다. API는 작업별 10회를 정렬한 상위 중앙값(6번째 값)과 p95(10회 표본에서는 최댓값)를 기록했다. 반복 조회는 같은 실행 인스턴스의 캐시가 채워진 상태이며 처음 조회·새 인스턴스에서는 DB를 읽고 계산한다.

D1 수치는 응답의 `X-D1-Rows-Read/Written`을 수집했다. 학생 조회의 쓰기는 기존 조회 횟수 제한 기록이다. 배치표 저장은 변경 전 전체 백업을 계속 생성한다. 표의 배치표 저장은 담임만 바꾼 경우이며 실제 변경한 분반·배정 수에 따라 쓰기가 달라진다.

브라우저는 FHD 1920×1080, Chromium/Edge, 지연 40ms, 다운로드 2MB/s, 업로드 1MB/s로 제한한 같은 로컬 서버에서 한 차례의 동일 경로를 비교했다. 아래 값은 분포나 실사용자의 평균이 아니다.

| 첫 문서+글꼴 준비 | 3,601ms | 1,443ms |
| 다음 문서+글꼴 준비 | 3,306ms | 335ms |

다음 문서의 공통 글꼴은 브라우저 캐시에서 읽어 전송량이 0B였다. 첫 방문에는 기존과 동일한 Pretendard 바이너리 2,057,688B를 받는다. 테스트 서버의 글꼴 캐시 유효 시간은 600초다. 실제 통신·서버 위치·실행 인스턴스 재사용·사용자 자료에 따라 운영 응답 시간은 달라진다. 이 시간은 **경과 시간이며 Workers의 청구 CPU 시간이나 운영 저장 속도가 아니다.**

## 변경 내용과 보호 장치

- 시간표 원본과 계산 결과는 실행 인스턴스당 최신 학기·시간표 버전 한 개만 보관한다. 결보강 변환도 같은 버전에 재사용한다. 학생 개인 자료, 인증 세션과 API 응답을 이 캐시에 넣지 않는다.
- 요청마다 D1에서 인증·현재 버전을 확인한다. 학기·자료 변경 후 버전이 달라지면 재계산하며 최종 버전 확인과 트랜잭션 충돌 검사를 유지한다. 학생·학급 명단은 현재 DB에서 읽는다.
- 학생 비고·이름만 바꾸면 수강 배정을 쓰지 않는다. 선택과목 변경 시 해당 과목만 저장한다. 배치표 저장 시 교실이 바뀐 분반과 새 분반에 해당하는 배정만 저장한다. 저장 전 전체 백업과 결보강 계획 보호 검사는 유지한다.
- 새 화면은 배치표 저장 응답으로 갱신하여 뒤따르는 조회를 없앴다. 기존에 열린 이전 화면에는 기존 전체 초기 자료 응답도 제공한다.
- 네 HTML에 반복되던 동일 글꼴을 공통 WOFF2로 분리했다. 라이선스와 원본 파일 해시는 유지한다. 관리자·교사 화면은 같은 메뉴 위치와 본문 시작점을 사용한다. 배치표 하단 설명·중복 안내를 없애고 상태·오류·실제 자료는 유지한다.

## 무료 티어와 검증 범위

Cloudflare 문서 기준 D1 Free는 하루 읽기 500만 행, 쓰기 10만 행, 총 저장 5GB다. 인덱스 쓰기도 계산에 포함된다. 이번 변경은 이를 줄이는 방향이며 사용량 한도를 늘리거나 요금제를 변경하지 않는다. [D1 공식 요금 안내](https://developers.cloudflare.com/d1/platform/pricing/)

Workers Free는 하루 10만 요청, 요청당 CPU 10ms, 메모리 128MB 제한이 있다. DB·통신 대기 시간은 CPU 시간과 다르다. 인스턴스 캐시는 성능 보조이며 유지가 보장되지 않는다. 이번 측정으로 모든 운영 저장이 CPU 10ms 이내라고 보장하지 않는다. 실제 한도 도달 여부는 Cloudflare 사용량에서 확인해야 한다. [Workers 공식 제한](https://developers.cloudflare.com/workers/platform/limits/)

기능 검증에는 캐시 갱신·학기 전환·비밀번호 변경 후 차단·학생 간 자료 분리·배정 미변경·전체 백업 보존·새 분반 명렬표를 포함한다. 브라우저에서 관리자 7개·교사 5개 메뉴의 고정 위치, 결보강 초안, 모바일, FHD 전체 교실, A3/A4 가로 한 페이지 인쇄를 확인한다. 운영 배포 전 전체 D1 백업을 보관하고 배포 후 업무 테이블과 비밀번호 해시를 읽기 전용으로 비교한다.

```sh
pnpm benchmark -- --output private/performance-after.local.json
pnpm benchmark:browser -- --output private/browser-performance-after.local.json
```

성능 보고서는 Git 제외 위치에 생성된다. 이전 버전 비교는 동일한 가상 자료와 측정 스크립트를 이전 체크아웃에서 실행한다. 운영 DB에서는 속도 측정을 위해 저장하거나 가상 자료를 등록하지 않는다.

## 학기별 서버 전달과 로딩 개선 · 2026-11-11

Windows, Node 24, Edge와 로컬 Miniflare/D1에서 학생 900명·배정 7,200개의 가상 자료를 사용했다. 브라우저 통신 지연은 40ms, 다운로드는 초당 2,000,000바이트로 설정했다. 매회 새 브라우저 컨텍스트로 5번 실행한 중앙값이다.

| 항목 | 변경 전 | 변경 후 |
| --- | ---: | ---: |
| 시수배당 첫 메뉴 선택부터 화면 표시 | 1,261ms | 505ms |
| 설정에서 관리자 새로고침 API 응답 크기 | 123,945바이트 | 954바이트 |
| 같은 API의 D1 읽기 행 수 | 9,005 | 5 |
| 같은 API의 브라우저 기록 응답 시간 중앙값 | 137ms | 68ms |

시수배당의 공통 모듈을 병렬로 불러오고, 학생 메뉴 이외의 관리자 조회·저장 후 갱신에서 전체 학생과 수강 배정 조회를 생략했다. 학생 목록은 학생 메뉴에 진입할 때 조회한다. 전달 자료는 서버에서 필요한 필드로 정규화하고 적용 시 식별자를 사용해 큰 자료를 다시 전송하는 과정을 줄였다.

측정은 가상 자료의 로컬 결과이며 운영 네트워크나 Workers CPU 한도 측정값이 아니다. 기존 내보내기·불러오기 형식과 관리자 권한·동시 수정 검증은 유지한다.

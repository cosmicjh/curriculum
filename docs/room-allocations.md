# 이동수업 배치표

관리자와 교사 화면의 **이동수업 배치표** 메뉴에서 사용합니다. 같은 로그인과 활성 학기를 사용합니다.

## 관리자 작성

1. **엑셀 불러오기**에서 인쇄용 배치표를 선택하거나 **시간블록 추가**로 시작합니다. 엑셀은 첫 행의 교실 제목, 학년 제목, 시간블록과 교시, `과목 분반 (교사, 교사)` 형식을 사용합니다. 파일을 불러오면 초안으로 표시됩니다.
2. **교실·담임 편집**에서 교실을 추가·수정·삭제합니다. 일반교실은 반 번호를 입력하면 학년과 합쳐 `3-1`처럼 시간표에 연결됩니다. 특별실은 반 번호를 비우고 교실명을 입력합니다. 2·3학년 담임을 한 편집 창에서 함께 수정하고 학년별로 보관합니다.
3. 시간블록 추가 시 학년을 지정합니다. 각 학년의 블록 제목을 눌러 교시를 입력하고, 교실 칸을 눌러 기존 분반을 선택하거나 새 과목·분반을 작성합니다. 담당 교사가 여러 명이면 쉼표로 구분합니다. 분반은 같은 학년·과목·분반 번호로 연결됩니다.
4. **배치표 저장**을 누르면 전체 초안이 한 번에 반영됩니다. 같은 교실 칸의 중복 분반, 시간블록 교시 중복, 창체·운영하지 않는 교시를 검사합니다. 저장 전 자료는 자동 백업하며 변경 이력을 남깁니다.

메뉴를 오가도 초안은 학기별로 탭 메모리에 남습니다. 브라우저 새로고침·종료 시에는 사라지므로 먼저 저장합니다. 다른 관리자가 먼저 저장했거나 학기가 바뀌면 덮어쓰지 않고 오류를 표시합니다. 배치표 새로고침은 미저장 변경을 버릴지 확인합니다.

## 교사 열람과 인쇄

2·3학년 배치표를 학년 전환 없이 한 표에서 함께 열람합니다. 교실을 선택하거나 과목·교사명으로 검색합니다. 교사 계정은 편집·저장할 수 없습니다. FHD(1920×1080), 24인치 모니터의 전체 교실 보기를 기준으로 배치표에서 가로 공간을 넓게 사용하고 열을 화면 폭에 맞춥니다. 교실 제목을 고정하고 표 안에서 세로로 스크롤하여 두 학년을 이어 읽습니다. 화면 상단의 메뉴·검색 영역을 줄이고 FHD 본문 12.5px·교사명 11.5px로 가독성을 높였습니다. 작은 화면에서는 교실 필터와 스크롤을 사용합니다.

인쇄 용지에서 **A3 가로** 또는 **A4 가로**를 선택한 뒤 **전체 한 장 인쇄**를 누릅니다. 검색·교실·학년 필터와 관계없이 전체 배치를 한 표로 출력합니다. 첨부 엑셀처럼 교실 제목을 한 번 표시하고 3학년과 2학년을 이어 배치하며, 교시와 학년별 담임도 포함합니다. 선택한 용지의 한 페이지에 맞게 배율을 계산합니다. 실제 인쇄 창의 용지를 선택한 크기와 맞추고 배율 100%, 머리글·바닥글 끄기를 사용합니다.

## 시간표 공통 사용

- 배치표는 기존 선택분반의 ID를 유지하고 공통 교실을 갱신합니다. 학생 수강 배정과 교사 시간표 원본을 삭제하거나 덮어쓰지 않습니다.
- 개인 학생·교사 시간표와 결보강은 같은 분반 교실을 사용합니다. 학생 시간표에는 담당 교사도 표시합니다.
- 배치표의 담당 교사 목록과 시간블록은 교사 시간표 수업을 분반에 연결하는 데 사용합니다. 여러 교사가 기재된 수업을 모두 같은 교시에 배정하지 않으며, 실제 교시는 기존 교사 시간표를 따릅니다. 교사 시간표 자료가 없는 이름은 저장 후 안내합니다.
- 교실·분반을 배치표에서 삭제해도 기존 학생의 수강 선택은 유지합니다. 삭제된 배치의 공통 교실은 비웁니다. 기존 교사 원본에 교실이 있으면 해당 원본 표시가 남을 수 있습니다.
- 선택분반 엑셀을 다시 올려도 배치표의 교실은 유지합니다. 배치된 분반의 과목명·분반명은 선택분반 메뉴에서 수정할 수 있고 배치표에도 함께 표시됩니다.
- 예정된 결보강 계획의 수업·교실을 바꾸는 변경은 기존 보호 규칙에 따라 차단됩니다. 해당 계획을 먼저 취소한 뒤 변경합니다.
- 열린 시간표는 다시 조회하고 배치표는 새로고침하면 최신 내용을 읽습니다. 실시간 자동 갱신은 제공하지 않습니다.

## 저장·복구와 검증

`migrations/0003_room_allocations.sql`을 적용한 뒤 Worker와 Pages를 함께 배포합니다. 학생·교사 실제 자료와 첨부 엑셀은 저장소·정적 배포에 넣지 않습니다. `room_allocations.content`는 교실·학년·시간블록과 공통 분반 ID·교사 목록만 보관합니다. 관리자 JSON 백업과 복원에 배치표도 포함됩니다. 과거 배치표가 없는 JSON 백업을 복원하면 그 시점의 배치표 없는 상태로 돌아갑니다. 결보강 기록까지 포함하는 전체 복구는 기존 D1 전체 백업을 사용합니다.

`pnpm test:allocation`은 가상 자료로 관리자 편집·탭 이동 초안·교사 열람·검색·모바일·FHD 전체 교실 보기를 검사합니다. 22개 교실·17개 시간블록의 긴 과목명 자료로 A3·A4 가로 PDF가 각각 한 페이지인지 검증합니다. `tests/allocation.test.mjs`는 권한·버전 충돌·분반 ID 유지·세 기능의 교실 반영·재등록·학기 분리·백업 복원을 검사합니다.
